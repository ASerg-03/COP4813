Assignment 10: Website Audit

This page contains the results of a Lighthouse audit performed on my website's homepage using mobile navigation mode.

Performance Metrics

  • First Contentful Paint: 0.8 seconds
  • Total Blocking Time: 50 milliseconds
  • Speed Index: 0.8 seconds
  • Largest Contentful Paint: 11.7 seconds
  • Cumulative Layout Shift: 0

Performance Analysis

The website received a performance score of 75. Most of the performance metrics were good, including First Contentful Paint, Total Blocking Time, Speed Index, and Cumulative Layout Shift. However, Largest Contentful Paint was significantly slower at 11.7 seconds.

Lighthouse identified opportunities to improve image delivery, estimating approximately 2,130 KiB in potential savings. It also identified an issue related to Largest Contentful Paint request discovery. Optimizing image sizes and formats could help improve the loading experience.

Additional Lighthouse Insights and Diagnostics

Insights

Lighthouse identified several factors affecting the website's performance. The most significant finding was the Improve Image Delivery recommendation, which estimated approximately 2,130 KiB in potential savings. This suggests that optimizing image file sizes and formats could improve loading performance.

Lighthouse also identified issues with LCP Request Discovery and the Network Dependency Tree. These findings indicate that the browser may take too long to discover or load the resource responsible for the largest visible element. Document Request Latency and Render-Blocking Requests were also identified as areas for improvement.

The LCP Breakdown and Third-Party sections provided additional information about the loading process and possible external resource impacts.

Diagnostics

The diagnostic results identified image elements without explicit width and height attributes. Providing these dimensions can help the browser reserve the correct amount of space for images before they finish loading. This can reduce unexpected layout changes.

Lighthouse also identified opportunities to minify CSS, reduce unused JavaScript, and avoid long main-thread tasks. The report estimated approximately 2 KiB in potential CSS savings and 180 KiB in potential unused JavaScript savings. Three long tasks were also detected.

These diagnostics provide additional information about possible improvements, although their estimated savings do not directly affect the overall Performance score.

Accessibility, Best Practices, and SEO

The website received a score of 100 in Accessibility, Best Practices, and SEO. These results indicate that the website performed well in the audited areas relating to accessibility, web development practices, and search engine optimization.

Conclusion

Overall, the Lighthouse audit showed that my website performs well in accessibility, best practices, and SEO. The main area that needs improvement is performance, particularly image loading. I could improve this by optimizing images and reducing unnecessary image file sizes.
